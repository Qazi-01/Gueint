# Gueint
A simple number guessing CLI game built in C.


## How to play
- a secret number is generated by the computer randomly between 1-100
- guess the number in 7 attempts or under
- if wrong, you get a hint
- Guess correctly and you win!


## Requirements
- GCC compiler
- C standard library

## How to compile & run
```
gcc main.c -o gueint
./gueint
```
